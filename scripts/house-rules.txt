HOUSE RULES. Follow every one. They separate a render that works from one that fails,
and a render that looks good from one that looks cheap.

These agree with Shotstack's own agent skill. To check a recipe before you render it:
  npm install -g @shotstack/cli
  shotstack validate recipe.json
It runs offline. No API key, no credits. It catches every mistake listed below.

USE THE CURRENT ASSET TYPES
- These are DEPRECATED. They still parse, and they produce worse output:
    "text" and "title"  ->  use "rich-text"
    "caption"           ->  use "rich-caption"
    "html"              ->  use "html5"
    "shape"             ->  use "svg"
    timeline.soundtrack ->  use an "audio" asset on its own track, "length": "end"
- "html5" is a self-contained HTML, CSS and JS page. Use it for motion graphics,
  charts and animated overlays. It preloads gsap, d3, anime and lottie.

STRUCTURE
- TRACK 0 IS THE TOP LAYER. The last track is the bottom. This is the reverse of
  z-index. Put captions and titles in the first tracks. Put background media last.
- Clips on ONE track must never overlap in time. Overlapping clips flicker. This is
  the most common structural mistake. Anything visible at the same time needs its
  own track.
- Sequential clips can share a track. "start": "auto" chains them.
- "length": "auto" is the asset's own duration. "length": "end" runs to the end of
  the timeline. Use "end" for music, captions and a watermark.

SHAPE
- Vertical 1080 x 1920 needs "output": { "size": { "width": 1080, "height": 1920 } }.
  There is no vertical preset. Custom sizes must divide by 2.
- output.resolution presets are horizontal only: preview 512x288, mobile 640x360,
  sd 1024x576, hd 1280x720, 1080 is 1920x1080.
- Add "quality": "high" and "fps": 25.

FONTS. READ THIS TWICE. A wrong font fails the whole render.
- font.family MUST equal the file basename of the URL you loaded, with no extension.
  Load  { "src": ".../JTUSjIg1_i6t8kCHKm45xW5rygbi49c.ttf" }
  Use   "font": { "family": "JTUSjIg1_i6t8kCHKm45xW5rygbi49c" }
  The human-readable name, such as "Montserrat Bold", FAILS with "Font not found".
- NEVER invent a Google Fonts URL. Google rotates the version and the hash, so a URL
  built from memory is a 404, and that fails the render. Copy one of these verbatim:
    Inter       UcCo3FwrK3iLTfvlaQc78lA2         https://fonts.gstatic.com/s/inter/v20/UcCo3FwrK3iLTfvlaQc78lA2.ttf
    Roboto      KFOmCnqEu92Fr1Me5WZLCzYlKw       https://fonts.gstatic.com/s/roboto/v50/KFOmCnqEu92Fr1Me5WZLCzYlKw.ttf
    Open Sans   mem8YaGs126MiZpBA-U1UpcaXcl0Aw   https://fonts.gstatic.com/s/opensans/v44/mem8YaGs126MiZpBA-U1UpcaXcl0Aw.ttf
    Montserrat  JTUSjIg1_i6t8kCHKm45xW5rygbi49c  https://fonts.gstatic.com/s/montserrat/v31/JTUSjIg1_i6t8kCHKm45xW5rygbi49c.ttf
    Poppins     pxiEyp8kv8JHgFVrFJDUc1NECPY      https://fonts.gstatic.com/s/poppins/v24/pxiEyp8kv8JHgFVrFJDUc1NECPY.ttf
    Oswald      TK3iWkUHHAIjg75GHjUHte5fKg       https://fonts.gstatic.com/s/oswald/v57/TK3iWkUHHAIjg75GHjUHte5fKg.ttf
    Bebas Neue  JTUSjIg69CK48gW7PXooxW5rygbi49c  https://fonts.gstatic.com/s/bebasneue/v16/JTUSjIg69CK48gW7PXooxW5rygbi49c.ttf
    Anton       1Ptgg87LROyAm0K08i4gS7lu         https://fonts.gstatic.com/s/anton/v27/1Ptgg87LROyAm0K08i4gS7lu.ttf
- Twelve fonts are built in and need no timeline.fonts entry: Arapey, Clear Sans,
  Didact Gothic, Montserrat, MovLette, NotoEmoji, Open Sans, Permanent Marker,
  Roboto, Sue Ellen Francisco, Uni Neue (weight 700 only), Work Sans.
- System fonts do not exist on the render engine. Arial, Helvetica and Times New
  Roman all fail.

TEXT
- Size text on the CLIP, not on the asset. A rich-text asset has no width or height.
  The clip width and height set the wrap box that align works inside. Without them
  the clip fills the frame and the text centres across the whole output.
- align.vertical is "top", "middle" or "bottom". It is NOT "center".
- A headline over footage needs help to stay readable. Use one of these, not both:
    "stroke": { "width": 3, "color": "#000000" }
    "background": { "color": "#000000", "opacity": 0.55, "borderRadius": 10 }
  A stroke eats a light or small font. Below 60px use the background.
- rich-text takes "padding" on the asset. It is not inside "background".
- A call to action reads as a button: dark text on
  "background": { "color": "#ffd400", "borderRadius": 18 }, "padding": 34.
- For a 1080 x 1920 frame a headline clip is about 940 wide at size 110 to 120.
  A subline is about 880 wide at size 54.

MOVEMENT
- Never leave a shot still. Give every background clip an "effect": alternate
  zoomInSlow, slideLeftSlow, zoomOutSlow, slideRightSlow.
- Every background clip: "fit": "crop" and "filter": "darken".
- Put "transition": { "in": "fade" } on every shot after the first.
- Keep motion to one vocabulary. Do not invent a new effect per clip. Entrances take
  about 0.6s, exits are faster.
- "offset": { "x": 0, "y": 0.06 } is a fraction of the frame. Positive y is UP.

SOUND
- Background music is an "audio" asset on its own track, "length": "end", with
  "effect": "fadeInFadeOut" and "volume": 0.5.
- Set "volume": 0 on background video clips so they do not fight the music.

HARD LIMITS
- Every src must be a public HTTPS URL. No local paths, no data: URIs, no signed URL
  that expires during the render.
- A video URL only works in a "video" asset. An image URL only works in an "image"
  asset. The wrong extension is rejected before rendering.
    image: jpg jpeg png gif webp bmp tiff avif svg
    video: mp4 m4v mov webm mkv avi 3gp flv
- Use ONLY the asset URLs given to you. Never invent one. An unreachable URL fails
  the whole render.
- Every clip needs "start" and "length". Shots must not leave a gap.
- text-to-image, image-to-video and text-to-speech are billed for every generation,
  INCLUDING in the free sandbox. They also make the render slower.
